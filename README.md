# soundcloud-rpc-medexplug
🎵 A plugin for [soundcloud-rpc](https://github.com/richardhbtz/soundcloud-rpc "soundcloud-rpc") electron client.

This plugin is a firefox extension that has been converted into a plugin format for the soundcloud rpc client. I have not written this code by myself. It is converted with Claude.

## Installation

 1. Download [soundcloud-rpc-medexplug.js](https://github.com/gothmiku/soundcloud-rpc-medexplug/blob/main/soundcloud-rpc-medexplug.js "soundcloud-rpc-medexplug.js") from the source files
 2. Hit F1 to open up the settings in soundcloud rpc
 3. Go to the plugins section and open the folder
 4. Put the file inside the folder
 5. Refresh and enable the plugin. Apply the changes
